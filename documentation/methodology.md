# Methodology

This document will be updated as the project progresses.

## 1. Excel Validation
- Inspect row and column counts
- Check missing values and duplicates
- Validate dates and numeric fields
- Recalculate revenue, cost, profit, and margin fields when possible
- Build PivotTables for initial KPI checks

## 2. SQL Analysis
- Create and load the transaction table
- Run validation queries
- Calculate revenue, cost, profit, margin, and order KPIs
- Use CTEs and window functions for ranking, growth, running totals, and trend analysis

## 3. Python Analysis
- Clean and standardize data with Pandas
- Perform descriptive statistics and EDA
- Examine distributions, outliers, correlations, and segment performance
- Create publication-ready visualizations

## 4. Power BI
- Build the analytical data model
- Create DAX measures for executive KPIs
- Design interactive views for trends, products, customers, and regions

## 5. Recommendations
Translate analytical findings into specific business actions supported by quantified evidence.
